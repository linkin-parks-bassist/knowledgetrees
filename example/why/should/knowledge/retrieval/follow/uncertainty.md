Uncertainty identifies the exact distinction an agent needs next, so it is the
cheapest routing signal through a semantic tree. Following that distinction avoids
loading answers the agent already knows and prevents speculative repository
exploration. As uncertainty narrows, traversal narrows; when uncertainty is resolved,
retrieval stops. The same mechanism helps an agent correct stale assumptions: check
the semantic owner of the surprising behavior, update the working model, and avoid
unnecessary edits when the recorded current truth already explains it.
