Project knowledge must remain valid when the repository is cloned on another
machine. Use repository-relative paths, environment-variable interfaces, stable tool
names, and portable predicates. A personal home directory, workstation-only install
path, or checkout location belongs in host-scoped global knowledge when genuinely
reusable, never hardcoded into a repository leaf.
