A knowledge tree is an authoritative, semantically structured knowledge substrate
whose directory choices progressively narrow a natural-language question and whose
Markdown leaves provide focused direct answers. It is both persistent memory and the
primary agent retrieval interface for its scope.

Leaves are semantically atomic but not uniformly tiny. A cohesive answer may be long
when its parts are normally retrieved together.
