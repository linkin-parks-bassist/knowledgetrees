A migration has failed if monolithic documents remain necessary, leaves mainly point
to those documents, a whole document is copied into another leaf, multiple knowledge
authorities must be synchronized, paths mirror file layout instead of questions, or
agents still need broad enumeration to find routine answers. Passing file-format or
proof verification alone does not establish a successful migration.
